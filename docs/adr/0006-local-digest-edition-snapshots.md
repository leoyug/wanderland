# 6. 内容简报保存独立的本地期刊记录

Date: 2026-09-28

## Status

Accepted

用户希望通过往期重新阅读每周的收藏，因此简报保存生成时的标题、描述、标签、封面及链接，而不是每次打开时重新查询当前收藏。记录保存在 IndexedDB 的独立表中，通过 repository 生成和读取；日期范围以生成时的本地自然日或周一至周日为准，同一范围只生成一份，首次阅读时间也保存在记录上。

编辑、归档或删除原收藏不修改已经生成的期刊。代价是会保留部分重复文字与图片 Blob；这份独立内容随本地备份一起导出与合并恢复，已有期刊不被覆盖，旧备份继续兼容。

首版是用户明确要求的本地流程与排版原型：今日总结由用户点击生成；打开工作台时为已结束且有内容的自然周补齐记录，并为最近已结束的一周提供过往收藏回顾。内容与封面只使用本地已保存信息，暂不调用外部热点检索或图像生成服务，也不增加浏览器权限。以后接入网络或 AI 时，先明确授权范围并使用持久化任务，不把重要状态留在内存队列中。
