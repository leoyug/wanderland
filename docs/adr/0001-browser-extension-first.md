# 1. 浏览器扩展优先

Date: 2026-09-04

## Status

Accepted

## Context

产品需要在用户浏览网页时低摩擦收藏当前内容，并在电脑浏览器中完成管理。独立 Web 应用需要用户复制链接，且无法直接读取登录后或客户端渲染的当前页面。原生应用则会引入额外的安装、跨平台和同步成本。

## Decision

V1 作为 Chrome/Edge 兼容的浏览器扩展交付。收藏由扩展入口触发，浏览和管理界面作为扩展内的完整网页在新标签页中打开。数据优先保存在本地浏览器，不要求账户或独立后端。

## Consequences

- 收藏当前页面、读取已渲染 DOM 和截取页面封面更直接。
- 管理界面仍可按常规 Web 界面开发，未来可迁移到托管网页。
- V1 无法提供手机收藏、跨设备同步和账户恢复。
- 没有后端爬取服务；公开页面由扩展后台尝试请求，失败时读取当前标签页已渲染的内容。
- 用户必须获得可理解的网站访问权限说明，并且权限范围应尽量小。
- 数据导出是必要能力，以降低浏览器本地数据丢失或未来迁移的风险。
