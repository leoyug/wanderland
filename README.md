# Wanderland

一个面向设计与开发工作的本地优先个人网络灵感库浏览器扩展。

## 项目文档

- `PRODUCT.md`：V1 产品范围、用户故事与验收标准。
- `DESIGN.md`：视觉语言、组件行为与可访问性要求。
- `TECH-STACK.md`：技术选型、数据边界与扩展运行模型。
- `CONTEXT.md`：领域术语与禁用表达。
- `ROADMAP.md`：当前进度、版本路线图与发布门禁。
- `docs/adr/`：已接受的架构决策。

## 本地开发

```bash
pnpm install
pnpm dev
```

开发环境默认使用空的本地收藏库。如需显式导入演示数据，打开 `dashboard.html?seed=demo`；生产构建不会触发该种子逻辑。收藏项、标签、快捷视图和后台任务保存在浏览器 IndexedDB 中。

开发服务器启动浏览器后，打开任意 `http://` 或 `https://` 页面，点击工具栏中的 Wanderland 图标即可在网页右上角打开快速收藏面板。扩展会保存页面元数据、经过清理的正文快照和可用封面；手工添加的链接会先保存为待补全，不会申请全站访问权限。浏览器内部页面等禁止脚本注入的页面会改为打开收藏库。

Dashboard 搜索覆盖标题、描述、域名、标签与正文快照。打开收藏项详情后，可阅读本地快照，编辑标题、描述、标签和封面，或删除收藏项；标签的重命名、合并和删除位于“设置 → 管理标签”。搜索、范围、标签、排序、排列和当前详情会同步到地址栏，刷新后可恢复。

## 本地备份与恢复

在 Dashboard 的“设置 → 备份与恢复”中下载 JSON 备份文件。备份包含收藏项（包括归档项）、标签、正文快照、用户封面、快捷视图及后台任务；文件保存在你选择的本地位置，不会上传到 Wanderland。恢复时先选择文件并核对数量，再点击“确认合并恢复”。相同内容类型和规范化网址的已有收藏项会跳过，现有内容不会被覆盖或清空。备份文件包含私人收藏与网页正文，请妥善保管。

AI API Key 和 Provider 设置不包含在备份中；迁移到新的浏览器配置文件后需要重新配置 AI。建议在升级、卸载或更换设备前先导出备份，并妥善保存多个历史副本。

运行完整质量检查：

```bash
pnpm check
```
